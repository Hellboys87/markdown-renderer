A fast, dependency-free Markdown renderer in a single parse.js, written from scratch to return exactly the HTML marked 18.1.3 returns — only faster. main.ts is the harness driver: it reads the case set and writes the rendered HTML.

## Run it

```sh
node main.ts # reads /input/cases.json, writes /output/html.json
```
